# ifs24048-pabwe-p2

Project Praktikum PABWE 2026 - Pertemuan 2: Praktik CSS & CSS Framework.

## Struktur Halaman

| Halaman | File | Teknologi |
|---|---|---|
| Landing Page Jasa AI | `index.html` | HTML + CSS murni |
| Daftar Blog AI | `blog.html` | Bootstrap 5 + Bootstrap Icons |
| Detail Blog AI | `blog-detail.html` | Bootstrap 5 + Bootstrap Icons |
| Curriculum Vitae | `cv.html` | Tailwind CSS 4 |

## Cara Menjalankan

1. Buka folder project ini di VS Code.
2. Install ekstensi **Live Server** jika belum ada.
3. Klik kanan pada `index.html` → **Open with Live Server**.
4. Jelajahi navigasi ke Blog dan CV melalui menu navbar.
5. Uji tampilan responsive lewat DevTools (Ctrl+Shift+M) pada lebar 1920px, 1366px, 768px, dan 375px.

## Catatan

- Data pribadi pada `cv.html` masih placeholder (`[NAMA ANDA]`, `[NIM ANDA]`, dst). Ganti dengan data asli sebelum dikumpulkan.
